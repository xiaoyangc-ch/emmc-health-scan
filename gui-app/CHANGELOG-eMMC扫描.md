# eMMC健康扫描 更新日志

## 1.0.3 (2026-11-10)

- 寿命字段区分「未定义」与「无数据」：芯片寿命计数器未实现显示 未定义（0x00，正常现象）；健康字段读取失败显示 无数据（-1），不再混用
- 综合结论只在至少一项健康数据有效时才判定，避免无数据被误判

## 1.0.2 (2026-11-10)

- 修复：深色主题下扫描结果部分单元格文字看不清（状态列改回主题文字色，与 AYA 硬盘检测页一致）
- 表格新增「生产日期」列（来自 eMMC CID，部分厂商该日期不精确，仅作参考）
- 网段输入示例改为 192.168.1.1；输入具体 IP 即扫描其所在网段全段（精确单台请用「IP 列表」）
- 寿命 B 显示 0x00 时文案改为「未定义」（JEDEC 定义：该区域未实现/未启用，属正常现象，非故障）

## 1.0.1 (2026-11-10)

- UI 优化：默认深色主题（AYA 风格），工具栏换图标按钮（开始/停止/报告）
- 表格结论列与预留块列彩色圆点标识，报告区新增标题栏与彩色统计徽标，底部新增状态栏
- 网段/IP 列表输入框加宽（IP 列表占满剩余宽度，长列表不再截断），示例统一为 192.168.1.x 写法并直接支持该格式
- 空结果时表格中央显示占位提示
- 更换应用图标：与 APM 图标同族（蓝渐变 + 白字），加入绿色健康脉搏元素

## 1.0.0 (2026-11-10)

首版发布。

- 扫描整个网段（自动探测本机网卡 /24，可指定网段或 IP 列表），并行探测 adb 5555
- 逐台读取 eMMC 健康度（JEDEC Ext CSD）：预留块 pre_eol_info、寿命估计 A/B、容量、厂商/型号/CID
- 读取途径：MMC ioctl 优先，debugfs ext_csd（文本/表格/连续 hex 流）与 health 兜底
- 汇总表格 + 每台中文明细 + 汇总 CSV（UTF-8 BOM），报告存 %APPDATA%/emmc-scan/reports
- 结论规则：pre_eol 主导（01 正常 / 02 警告 / 03 紧急）；寿命 ≥80% 计警告、超过设计寿命计紧急；无数据计未知
- 内置 adb 与双架构设备端工具（armv7/arm64），免安装依赖
- 基于 AYA（liriliri/aya）架构改编：custom titlebar + Luna Toolbar/DataGrid，单页无侧栏

## 1.1.0 (2026-11-10)

- 新增「内存快测」：工具栏勾选后，扫描时对每台设备推送 memtest 工具做写读校验（9 种位型，自动取可用内存约 50%，单台上限 60 秒），表格新增「内存快测」列（通过 XM / 失败 N处 @偏移 / 通过(部分)）
- 内存快测无需 root，独立于 eMMC 结果；报告 CSV 与明细同步新增该列
